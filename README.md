Full-stack приложение для учета личных финансов, состоящее из Telegram-бота для быстрого ввода данных и веб-дашборда с интерактивной визуализацией и аналитикой. Проект демонстрирует принципы построения гибридных систем, объединяющих мессенджер-интерфейс для пользовательского ввода и веб-интерфейс для аналитической работы с данными.

## Описание предметной области

Управление личными финансами требует регулярного ввода данных и наглядного представления аналитики. Традиционные решения (электронные таблицы, мобильные приложения) часто либо неудобны для быстрого ввода, либо не предоставляют достаточной аналитической гибкости.

Данное решение реализует гибридную архитектуру, разделяющую задачи ввода и анализа:

- **Telegram-бот** обеспечивает мгновенный ввод расходов через привычный интерфейс мессенджера с валидацией формата и мгновенной обратной связью.
- **Веб-дашборд** предоставляет интерактивную аналитику с визуализацией данных, агрегацией по категориям и временным рядам.
- **REST API** выступает связующим звеном между ботом, базой данных и веб-интерфейсом, обеспечивая единую точку доступа к данным.

Архитектура проекта спроектирована с учетом масштабируемости: база данных SQLite может быть заменена на PostgreSQL через ORM (SQLAlchemy) без изменения бизнес-логики приложения.

## Технологический стек

- **Язык программирования:** Python 3.11+
- **Telegram Bot Framework:** Aiogram 3.x (асинхронный фреймворк)
- **Web Backend:** Flask (REST API)
- **ORM:** SQLAlchemy (архитектура, готовая к переходу на PostgreSQL)
- **База данных:** SQLite (локальная разработка), PostgreSQL (продакшен)
- **Анализ данных:** Pandas (агрегация, группировка, временные ряды)
- **Визуализация:** Plotly (интерактивные графики)
- **Frontend:** HTML5, CSS3 (адаптивный дизайн, Grid/Flexbox)
- **Тестирование:** Pytest
- **Управление конфигурацией:** python-dotenv
